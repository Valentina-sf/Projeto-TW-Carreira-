# 🚀 Carreira+

**Carreira+** é uma plataforma desenvolvida como projeto acadêmico com o objetivo de orientar estudantes e iniciantes na área de Tecnologia da Informação por meio de roadmaps de carreira.

## 📌 Objetivo

Auxiliar usuários a conhecerem diferentes áreas da TI e identificar as habilidades, tecnologias e etapas necessárias para seguir a carreira desejada.

## ✨ Funcionalidades

- Visualização de roadmaps de carreira;
- Exploração de diferentes áreas da TI;
- Informações sobre habilidades e tecnologias;
- Interface moderna e intuitiva.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Figma (Protótipo)
- Git e GitHub
