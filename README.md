# Projeto-TW-Carreira-
Projeto para a disciplina de Tecnologias Web

## Descrição do Projeto

Carreira+ é um site desenvolvido com o objetivo de auxiliar pessoas que estão em busca de uma oportunidade de emprego.
A plataforma busca reunir informações sobre vagas de trabalho em um único ambiente, facilitando a pesquisa e o acompanhamento de oportunidades por parte dos usuários.

---

## Funcionalidades

As funcionalidades previstas para o projeto incluem:

- Cadastro de usuários;
- Consulta de vagas de emprego;
- Pesquisa de oportunidades por área de interesse;
- Organização de vagas salvas pelo usuário;
- Acompanhamento de candidaturas.

---

## Motivação

Muitas pessoas enfrentam dificuldades durante a busca por emprego, seja pela grande quantidade de informações disponíveis ou pela dificuldade em acompanhar oportunidades encontradas em diferentes plataformas.
O projeto surge com a proposta de oferecer um ambiente simples e organizado para auxiliar usuários durante sua jornada de recolocação profissional.

---

## Informações Adicionais

O projeto será desenvolvido como parte das atividades da disciplina de Desenvolvimento Web.
A proposta encontra-se em fase inicial de definição e poderá receber novas funcionalidades ao longo do desenvolvimento.
